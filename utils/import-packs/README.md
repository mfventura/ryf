# ⚠️ Scripts legacy

Estos scripts poblaban los compendios pegándolos en la consola de Foundry. **Ya no son la fuente de los datos**: los compendios se generan ahora desde los JSON de `packs/_source/` con `npm run pack` (CLI oficial de Foundry, ver README principal).

Se conservan solo como referencia histórica. Si editas contenido de compendio, hazlo en los JSON de `packs/_source/` (o dentro de Foundry con el candado abierto y luego `npm run unpack`).
